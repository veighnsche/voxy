# Security Policy

## Supported Versions
Voxy is pre-release. Security fixes are provided on the latest `main` branch.

## Reporting a Vulnerability
Please do not open public issues for security vulnerabilities.

Report vulnerabilities using GitHub private reporting:
https://github.com/veighnsche/voxy/security/advisories/new

Include:
- Affected commit/version
- Reproduction steps
- Potential impact
- Suggested mitigation (if known)

We will acknowledge receipt and follow up with remediation status.
